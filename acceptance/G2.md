# G2 — Metering + Quota + Billing

Branch: `reef-control-plane`

## Delivered

- Persisted per-account token quota with used, remaining, and limit values.
- Fail-closed quota enforcement before model routing.
- Actual provider usage is written to the DB usage ledger and debits quota.
- Cost is computed from the configured local price table and stored with usage.
- Billing adapter interface with local DB-backed billing ledger default.
- Stripe billing adapter is explicitly stubbed and throws until a real integration is supplied.
- `GET /v1/quota` returns sourced DB ledger values and evidence links.
- Quota decisions are gateway evidence links, including over-quota denials.
