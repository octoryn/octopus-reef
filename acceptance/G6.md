# G6 — Editor Client Wired To Real Control Plane

Branch: `reef-control-plane`

## Delivered

- Commercial `GatewayProvider` now supports signed gateway JWTs via `accessToken`, while preserving the existing `licenseToken` stub gateway path.
- Server session model accepts `accessToken` and prefers it over local license token auth for the real gateway.
- IDE settings/env wiring now supports:
  - `reef.gateway.url` / `REEF_GATEWAY_URL`
  - `reef.gateway.accessToken` / `REEF_GATEWAY_ACCESS_TOKEN`
  - `reef.gateway.licenseToken` / `REEF_LICENSE_TOKEN`
  - `reef.account.ssoUrl` / `REEF_GATEWAY_OIDC_ISSUER`
- IDE provider enum includes `gateway`.
- Bundled daemon env passes gateway URL, JWT, license token, and priority tier.
- Local SSO accounts are priority-capable in the dev control plane so one offline flow covers SSO, team, entitlement, quota, and priority routing.
- G6 source test uses the commercial client against the real gateway service: local OIDC SSO -> signed JWT -> `GatewayProvider` -> `/v1/completions` -> quota/team/plan reads -> `/v1/verify` green -> one-byte ledger tamper -> `/v1/verify` red.
- Existing server commercial stub tests still pass, proving the offline stub path remains intact.
