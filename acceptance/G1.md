# G1 — Inference Gateway + Entitlement

Branch: `reef-control-plane`

## Delivered

- Signed JWT issue/verify path for gateway callers.
- Fail-closed `POST /v1/complete` and `/v1/completions`.
- Local admin provisioning endpoint for offline account/license/JWT setup.
- DB-backed account, license, quota, and usage records across SQLite and Postgres adapters.
- Entitlement enforcement for `inference:complete`.
- Model provider routing to real `BedrockProvider` when `AWS_BEARER_TOKEN_BEDROCK` is set; otherwise deterministic local provider.
- Evidence links for auth, entitlement, route, and metering decisions.
- Unentitled and invalid-token denials are recorded as evidence and do not route to the model provider.
