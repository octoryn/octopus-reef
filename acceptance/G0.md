# G0 — Scaffold + Verifiable Gateway Ledger

Branch: `reef-control-plane`

## Delivered

- New `@octopus-reef/gateway` TypeScript/Node package in `packages/gateway`.
- HTTP service shell with `GET /health`, `GET /ready`, `GET /v1/verify`, and a fail-closed local admin decision endpoint.
- DB interface with SQLite default, Postgres adapter, and shared migrations.
- Gateway ledger built on `octopus-evidence` (`createEvidence`, `nextLink`, `verifyEvidence`, `verifyChain`, `chainHead`).
- Store-untrusting verification that reloads ledger rows from the DB and checks evidence integrity, link bindings, expected length, and expected head.
- Dockerfile, docker-compose service plus Postgres, and `CONFIG.md` env documentation.
