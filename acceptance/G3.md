# G3 — Account + License

Branch: `reef-control-plane`

## Delivered

- `POST /v1/signup` creates an account, password material, license, entitlement, quota, and signed JWT.
- `POST /v1/login` verifies password credentials and issues a signed JWT.
- Failed login is denied and evidence-backed.
- `POST /v1/license/revoke` revokes the active license for an authenticated account.
- Completion after revoke is denied by the DB entitlement check.
- Account signup, password auth, license provision, revoke, and entitlement denial are gateway evidence links.
